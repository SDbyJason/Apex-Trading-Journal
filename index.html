What is Apex

A Journal Built for
Serious Traders

Apex Trading Journal is a professional-grade analytics and journaling application designed for active cTrader traders. It provides a structured, data-driven framework for reviewing performance, identifying patterns, and making better trading decisions.

The application connects to the cTrader Open API to automatically retrieve your closed trade history and account statistics. All data access is strictly read-only — Apex never interacts with open positions, pending orders, or any trade execution layer.

Think of it as your personal trading coach: surfaces win rate by session, average risk-reward, drawdown periods, and behavioral patterns — so you can continuously improve.

Trust & Safety

Security & Data Privacy

Apex Trading Journal requests a single cTrader Open API permission. This section documents exactly how that permission is used and the strict technical boundaries enforced by the application.

🛡️
Apex Trading Journal does not place, modify, or close trades.
The application contains no trade execution logic. It is technically incapable of interacting with open orders or positions.
Permission Requested
Access any available account info
This is the only cTrader API permission requested. Used exclusively to retrieve read-only data:
✓Retrieve closed trade history and fill data
✓Read account balance and equity snapshots
✓Access symbol and instrument metadata
✗Place, modify, or cancel any order — never used
✗Access funds or payment methods — never used
Data Handling
Privacy & Storage Policy
All data is handled with strict privacy standards:
✓Trade data stored securely in user's own cloud account
✓Data is never sold, shared, or transmitted to third parties
✓API tokens scoped to individual user sessions only
✗Credentials never stored in plain text or logged
✗No data aggregation across user accounts
